# Créditos y licencias

Este repositorio (**inir-niri**) es la capa de personalización de **Elvislrd**:
widgets, popups y archivos de configuración. No incluye el shell ni el compositor.

de tu distribución.

## Archivos derivados de iNiR

Varios archivos de `widgets/`, `popups/`, `common/`, `iris/` y `config/inir/`
parten del código de iNiR y por eso se distribuyen bajo **GPL-3.0**
(ver [`LICENSE`](LICENSE)).

Las capturas de `docs/screenshots/` son mías y del wallpaper incluido; puedes
usarlas para mostrar el setup.
